Miniplan Event Selection Redesign

This project involved modernizing an outdated event selection page, originally designed with standard checkboxes, into an engaging and user-friendly interface. I redesigned the visuals, transforming the checkboxes into a sleek, modern design that retained their functionality while significantly improving the user experience. To enhance usability, I added "Select All" and "Deselect All" buttons, enabling quick bulk actions. Additionally, I implemented dynamic text that updates in real-time to display the number of selected events, providing users with clear feedback. To further customize the experience, I incorporated functionality to limit the maximum number of selectable events, ensuring flexibility for various use cases. Note: Screenshots are from a test environment and includes placeholder data.

Sitemap with Dynamic Search Bar

This project involved designing an interactive sitemap to enhance website navigation and user experience. The sitemap includes a search bar that dynamically highlights matches as users type, making it easy to locate specific pages or sections. To provide clear and immediate feedback, the interface also displays the number of results found, updating in real-time as the search query changes. Additionally, I implemented functionality to hide certain links based on the user’s security level, ensuring that only authorized content is accessible. This functionality was achieved using efficient JavaScript, combining user-centered design with robust security considerations to simplify navigation while maintaining data integrity. Note: Screenshots are from a test environment and includes placeholder data.
